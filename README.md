# compbio-lab

A 7-session course on population genomics for students of physical anthropology, biology and biotechnology: terminal basics, human genetic variation, and running and interpreting PCA and ADMIXTURE on a small dataset (MXL as the admixed group).

See [COURSE_OUTLINE.md](COURSE_OUTLINE.md) for the session-by-session plan.

Laptop budget: 8 GB RAM, 4 cores, Windows with WSL2.

Environment: `compbio-lab` (conda), providing plink, plink2, bcftools, ADMIXTURE and R. The env spec lives in the shared `environments` repo, not in this project.
